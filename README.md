# 🎓 Scholar Institute Website

A modern full-stack educational institute platform built using React.js, ASP.NET Core, and Supabase. The platform provides a seamless experience for students and administrators while being designed for future AI-powered enhancements through a Retrieval-Augmented Generation (RAG) chatbot.

## 🚀 Overview

Scholar Institute is a comprehensive educational management platform that enables institutes to showcase courses, manage student interactions, and streamline administrative operations. The project follows a scalable architecture with a React frontend, ASP.NET Core backend, and Supabase as the cloud database solution.
